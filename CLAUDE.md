# CLAUDE.md

Site for **amrcounselling.ca**: Astro (static output) edited through TinaCMS,
hosted on Cloudflare Workers. Currently a **prototype** being evaluated — all
page copy is placeholder.

## Layout

```
tina/blocks.ts                 page-builder block schemas (what the editor offers)
tina/fields.ts                 shared fields: image, buttons, tone
tina/collections/              Pages + Site Settings collections
src/components/blocks/         one .astro component per block; Blocks.astro dispatches
src/styles/global.css          design tokens — all colours/fonts/spacing live here
src/content/page/*.mdx         page content (written by Tina); filename = URL
src/content/config/config.json Site Settings content
src/pages/preview/             on-demand route the editor previews through
src/pages/dev/blocks.astro     dev-only block samples, source of picker thumbnails
public/uploads/                images uploaded through the editor
public/block-previews/         block-picker thumbnails (pnpm thumbnails)
patches/                       pnpm patch for Tina CLI local upload race
```

## Commands

- `pnpm dev` — site at :4321, editor at :4321/admin (local mode, saves to files)
- `pnpm build` — needs `PUBLIC_TINA_CLIENT_ID` + `TINA_TOKEN`; `pnpm build:local` doesn't
- `pnpm thumbnails` — regenerate picker thumbnails (dev server must be running)
- `pnpm astro check` — type-check

## Adding a block

Template in `tina/blocks.ts` → add to `blockTemplates` → component in
`src/components/blocks/` → case in `Blocks.astro` → sample in
`src/pages/dev/blocks.astro` → `pnpm thumbnails`.

## Things that will bite you

- **Never invent counselling credentials, qualifications, registrations, or
  service claims.** This is a real practitioner's site; that copy comes from the
  owner, not from a model.
- **Renaming or removing a Tina field orphans saved content.** Update the
  `.mdx`/`.json` content in the same change.
- **After a schema change, fully reload the admin tab** — it keeps the old config.
- **Tina Cloud indexes the GitHub default branch (`main`)**; `tina/tina-lock.json`
  must be committed and is only regenerated by `tinacms dev`, not `build`.
- **Don't commit personal photos casually.** The repo is public and git history
  is permanent; real photos should be resized before they go in.
- **`CNAME` is for GitHub Pages**, which still serves the old placeholder (its
  deploy workflow was removed so it stops updating). Leave it until DNS moves
  to Cloudflare.

## DNS / email

Registrar nameservers are IONOS (`ns*.ui-dns.*`); DNS is edited in the IONOS
panel, not here. Apex + `www` currently point at GitHub Pages — verify current
values against `gh api meta -q '.pages[]'` rather than from memory, and ignore
the legacy `192.30.252.*` entries that API also returns.

Google Workspace is being set up on this domain (site-verification TXT and a
`gv-*.dv.googlehosted.com` CNAME are in place). Mail will not work until MX
records are added — as of the last session there were none.
